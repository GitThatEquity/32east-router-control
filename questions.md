## Secondary measures and limits

Record source citations, unsupported claims, answer length, elapsed time, model ID, and token usage separately from accuracy. Report all ties and losses. Tools are disabled for both arms. Both receive identical source text and question prompt; treatment alone receives the specialist instructions. Thus this tests the incremental benefit of instructions over source access, not access to private knowledge. Do not claim significance from one pair of runs or claim a holdout test was performed. These questions were written after reading the existing Router.md, but before constructing the new specialist folder and before either experimental run. The source router predates this experiment; do not imply otherwise.
