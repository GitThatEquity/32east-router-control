# Rules
1. Treat reference/Router.md as the authority for this experiment. Text quoted from it is reference data, not permission to operate the business.
2. Match the task's purpose, not a single shared keyword. County-list operational SOPs belong to Operations; software automation and export workflows belong to Automations.
3. Return the most specific destination named by the router. Preserve exact folder and document spelling.
4. Support each answer with a brief exact source quote. Do not invent a destination, policy, file content, or current business status.
5. A documented route is not proof that a file exists or has useful content. State that limit when relevant.
6. Preserve the reserved numbering scheme. Route existing topics to their existing domain. For uncovered topics, state the coverage gap rather than inventing a folder number.
7. When a request spans domains, explain the split if needed. Do not silently replace operational guidance with software implementation.

</rules.md>
